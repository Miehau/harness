name: start
description: Start an Agent Plan task using native Codex worktrees, implementation workers, verification and independent reviews; no runner daemon.
---

Read [the native binding](../../native.md), [the workflow contract](../../shared/contract.md)
and [the task record](../../shared/task-record.md). If unconfigured, onboard first.

Save a durable task brief, observable acceptance criteria, risk-selected roles and
configuration snapshot before dispatch. Resolve only material unanswered decisions.
Choose the short path for small understood tasks: one writer, verification and the
required parallel reviewers. Use native delegation and isolated worktrees within
actual capabilities and permissions; unavailable or unsupported role routing blocks
rather than silently changing runtime. A direct executor requires the user's explicit
choice and cannot claim independent review or completion.

Integrate serially, verify the exact candidate, dispatch parallel requirements/AC,
correctness and applicable specialists, and resolve blocking findings. Save report
references, pending operations and hosted delivery evidence. Publish only with
existing authorization. Report candidate SHA, AC evidence, verification, review roles,
remaining blockers and PR/MR; merge waits for exact-candidate owner approval.
